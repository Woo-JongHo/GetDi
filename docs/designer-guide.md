# GetDi 사용 가이드

> **쉽게**: 좋은 글을 골라 읽고, 그 글에서 인스타 카드 초안을 뽑는 도구다.
> 카드를 처음 만들 때, 만든 카드를 고칠 때 이 문서를 본다.

이 문서는 개발을 모르는 사람을 위해 썼다.
코드를 읽을 필요도, 고칠 필요도 없다.
터미널에 두 줄을 붙여넣는 것이 전부다.

---

## 1. 이 도구가 하는 일

디자인 아티클 262건이 이미 안에 들어 있다.
출처는 Nielsen Norman Group이라는 UX 연구 기관이다.

그중 하나를 고르면 이런 일이 일어난다.

1. 원문을 그대로 보여준다. 문단 순서와 본문 이미지가 원본과 같다.
2. 한국어로 번역해 준다.
3. 무엇이 핵심인지 분석한다.
4. 인스타 카드 6장 안팎의 문구 초안을 만든다.
5. 말로 고쳐 달라고 하면 고친 버전을 새로 만든다.

**아직 안 되는 것**: 완성된 이미지 파일로 뽑기, 인스타에 올리기.
문구와 배치 계획까지가 지금 범위다.

---

## 2. 켜기

터미널을 열고 아래를 순서대로 붙여넣는다.

```bash
cd ~/woo/00_project/18_GetDi
npm install
npm run dev
```

`npm install`은 **처음 한 번만** 하면 된다.
다음부터는 마지막 줄만 있으면 된다.

터미널에 주소가 뜨면 브라우저에서 연다.

```
http://localhost:5545/
```

**끌 때**는 터미널에서 `Ctrl` + `C`를 누른다.
브라우저 탭만 닫으면 뒤에서 계속 돌고 있다.

터미널 창은 켜 둔 채로 둬야 한다.
창을 닫으면 사이트도 함께 꺼진다.

## 3. 화면 여섯 개

맨 위 줄에 메뉴가 있다.

| 메뉴 | 하는 일 |
|---|---|
| Library | 아티클 목록. 여기서 시작한다 |
| Analysis | 참고할 인스타 게시물의 디자인을 뜯어본 결과 |
| Usage | 지금까지 쓴 AI 사용량 |
| Log | 방금 무슨 작업이 돌았는지 기록 |
| Present | 발표용 화면 |
| Guide | 이 문서. 막혔을 때 여기서 본다 |

평소에는 Library만 쓴다.
나머지는 궁금할 때 열어 보면 된다.

---

## 4. 카드 만드는 순서

### 4-1. 아티클 고르기

Library에서 검색창에 단어를 넣거나 목록을 훑는다.
카드를 누르면 원문 화면으로 들어간다.

목록의 모든 아티클에 본문이 다 들어 있지는 않다.
본문까지 받아 둔 것만 다음 단계로 갈 수 있다.

### 4-2. 읽고 번역하기

원문 화면에서 한국어 탭을 누르면 번역이 시작된다.

**처음 한 번만 시간이 걸린다.**
한 번 번역한 글은 저장되므로 다음에는 바로 뜬다.

번역 중에는 화면을 닫지 말고 기다린다.

### 4-3. 분석하기

원문 화면의 `이 아티클 분석하기`를 누른다.

누르기 전에는 아무 일도 일어나지 않는다.
비용이 드는 작업이라 일부러 수동으로 만들어 뒀다.

분석이 끝나면 이런 것이 나온다.

- 이 글을 한 문장으로 줄이면 무엇인가
- 핵심 주장 3~5개
- 각 주장의 근거가 원문 어디인가
- 카드 몇 장으로 어떻게 나눌지에 대한 계획

### 4-4. 카드 초안 만들기

Library 카드를 누르면 생성 확인 창이 뜬다.
확인하면 카드 6장 초안이 만들어진다.

만들어지는 것은 **문구와 배치 계획**이다.
완성된 그림 파일이 아니다.

### 4-5. 고치기

Draft 화면에서 말로 고쳐 달라고 쓴다.

```
3번 카드 제목이 너무 딱딱해. 질문형으로 바꿔줘.
```

고칠 때마다 **새 버전이 쌓인다.**
이전 버전은 사라지지 않으니 마음껏 시켜도 된다.

---

## 5. 이 도구가 까다롭게 구는 이유

가끔 "못 하겠다"고 하거나 빈칸으로 두는 경우가 있다.
고장이 아니라 일부러 그렇게 만들었다.

**원문에 없는 말은 만들지 않는다.**
그럴듯한 숫자나 사례를 지어내면 그 카드는 나중에 못 쓴다.
그래서 근거가 없으면 아예 안 쓴다.

**원문의 말투를 세게 바꾸지 않는다.**
원문이 "그럴 수도 있다"고 했으면 "그렇다"로 바꾸지 않는다.

**출처가 불분명한 이미지는 내보내지 않는다.**
화면에서는 보이지만 최종 결과물에는 안 담긴다.

**참고한 인스타 계정의 캐릭터나 로고는 따라 그리지 않는다.**
구조와 분위기만 참고 대상이다.

카드 문구가 밍밍하게 느껴진다면 대개 원문에 근거가 약해서다.
그럴 때는 다른 아티클을 고르는 편이 빠르다.

---

## 6. 안 되는 것

- 인스타에 자동으로 올리기
- 완성된 이미지 파일 내보내기 (준비 중)
- 새 아티클을 직접 가져오기 — 수집은 다른 도구가 맡는다
- 여러 사람이 같이 쓰기 — 내 컴퓨터에서만 돈다

---

## 7. 막혔을 때

**브라우저에 아무것도 안 뜬다**
터미널이 아직 켜져 있는지 본다. 꺼졌으면 `npm run dev`를 다시 친다.

**번역이나 분석이 안 끝난다**
Log 메뉴에서 지금 무슨 작업이 도는지 볼 수 있다.
10분이 넘으면 실패로 처리되니 그때 다시 누른다.

**AI를 얼마나 썼는지 알고 싶다**
Usage 메뉴에 그날 쓴 양이 나온다.

**카드가 마음에 안 든다**
Draft 화면에서 계속 고쳐 달라고 하면 된다.
버전이 쌓일 뿐 원본이 망가지지 않는다.
